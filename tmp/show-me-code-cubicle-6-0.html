02 / The three briefs

Choose the evidence you can own.

Each statement is a product brief disguised as a feature list. The differentiator is the managed workflow around the model.

PROBLEM 01 / DATA

AI-Powered Data Intelligence Platform

No named track sponsor in the PDF

A business user types a data need. The system plans, runs, checks, and explains the collection workflow.

  • Plain-English request understanding
  • Permitted-source collection and workflow execution
  • Cleaning, structuring, validation, deduplication
  • Traceable sources, history, search, export
Proof to show: one live request becomes a reproducible, inspectable dataset.
PROBLEM 02 / MEDIA / CLOUDINARY

AI-Powered Impact & Sustainability Media Platform

Track sponsor: Cloudinary

Turn field photos and videos into organized evidence, measurable change, and campaign-ready stories.

  • Project, location, and timeline organization
  • Activity and visual-signal detection
  • Before-and-after comparison
  • Metadata, semantic search, visual reports
Proof to show: raw media becomes a visual evidence trail, not just a gallery.
PROBLEM 03 / EDGE / QDRANT

AI-Powered Edge Memory & Intelligence Platform

Technology partner: Qdrant

Keep useful memory and fast retrieval on-device, then synchronize intelligently when the network returns.

  • Offline vector and hybrid search
  • Local/cloud placement decisions
  • Intermittent connectivity and conflict handling
  • Memory, search, sync, and activity UI
Proof to show: meaningful edge-to-cloud reasoning, not a local vector database demo.

04 / Edge-specific reading

Qdrant Edge is a behavior, not a badge.

The statement explicitly rejects "just run a local vector database." Show what the system knows, what it sends, and what it does when both copies disagree.

Offline-first memory loop

A believable edge demo has two states and a visible transition between them.

On device

Qdrant Edge

Local semantic memory, vector + hybrid retrieval, privacy-sensitive context, activity log.

<->
When online

Qdrant Server

Relevant knowledge sync, cross-device context, conflict resolution, and audit history.

  • Pull the network cable in the demo; local search still succeeds.
  • Show the policy that chooses local-only, sync-now, or defer.
  • Change the same memory on both sides and resolve it explicitly.

What judges can verify

LatencyLocal search without a network round trip.
ResilienceWork continues through intermittent connectivity.
PrivacyRaw sensitive data can stay local while useful context syncs.
ReasoningSync decisions are explainable, not arbitrary.
ObservabilityMemory, results, status, and activity are inspectable.
TraceabilityUpdates and conflicts leave an audit trail.
05 / Build advice

A small, auditable slice beats a huge claim.

Pick one user, one repeatable workflow, and one measurable outcome. Depth with evidence is more persuasive than breadth.

Recommended demo sequence

  1. State the user and the painful decision they need to make.
  2. Run the happy path with real or realistic permitted inputs.
  3. Open the evidence drawer: source, timestamp, transformation, confidence.
  4. Break one assumption: duplicate, conflict, poor media, or lost network.
  5. Show the resulting action, report, export, or recovered offline answer.
