# Domain documentation

This repository uses a single-context domain model.

## Primary context

Read `CONTEXT.md` at the repository root before implementing or changing product behavior.

## ADRs

Architecture and hard-to-reverse decisions belong in:

`docs/adr/`

Create an ADR only when a decision is:

- Hard to reverse
- Surprising without context
- Based on a real trade-off

## Scope

Keep `CONTEXT.md` limited to domain vocabulary and product decisions. Do not use it for implementation details, temporary notes, or task lists.
