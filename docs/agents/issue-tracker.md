# Issue tracker

This repository uses local Markdown issue files.

## Location

Issues live under:

`.scratch/<feature>/`

Each feature may contain:

- `issue-001.md`
- `issue-002.md`

## Workflow

- `/to-tickets` writes local Markdown issues.
- `/triage` is not currently installed.
- Work is selected by issue status and dependencies.
- Completed issues should include a short implementation summary.

## GitHub migration

If this directory becomes a GitHub repository later, update this file and migrate active issues to GitHub Issues if desired.
